# 2026-05-03 — Eliminación de Langfuse Tracing

## Objetivo
Excluir toda la integración de Langfuse Tracing del proyecto novacifer.com.

## Cambios realizados

### Ficheros eliminados
- `assets/js/langfuse-tracing.js` — Librería core de tracing (14KB)
- `LANGFUSE_TRACING.md` — Documentación de la integración

### Ficheros modificados

#### `_layouts/default.html`
- Eliminado el `<script>` que cargaba `langfuse-tracing.js` (líneas 109-110)

#### `assets/js/main.js`
- Eliminadas las variables globales `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY`, `LANGFUSE_BASE_URL`
- Eliminadas todas las llamadas a `LangfuseTracing.startTrace()`, `LangfuseTracing.traceSync()`, `LangfuseTracing.event()`
- Eliminado el tracking de clicks por delegación de eventos
- Eliminado el tracking de scroll depth
- Eliminado el tracking de errores de window (`error`, `unhandledrejection`)
- Eliminado el override de `console.error` para debug
- Conservada la lógica de UI pura: animación de engranajes en hover, efecto typewriter, flicker en carga

- `grep -ri langfuse` sobre el proyecto: **0 resultados**
